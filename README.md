# זינוק · משחק הלימודים

משחק לימודים אישי בעברית: כל מבחן הוא עולם, כל פרק הוא שלב, ובסוף כל עולם יש בוס. הדמות שלך מתחזקת רק משליטה אמיתית בחומר.

- **לשחק:** דאבל־קליק על `index.html` (בלי שרת, בלי התקנות), או בגרסה המפורסמת ב־GitHub Pages.
- **להוסיף חומר:** שמים קבצים ב־`materials/`, ואומרים ל־Claude Code ״תוסיף חומר״ (או `/new-material`). נוצר קובץ ב־`packs/`.
- **לייבא:** במשחק לוחצים ״ייבוא חבילה״ ובוחרים את הקובץ מ־`packs/`.
- **גיבוי:** ההתקדמות נשמרת ב־localStorage של הדפדפן. במסך ״גיבוי והגדרות״ מורידים קובץ גיבוי מדי פעם.

הפורמט של חבילה: [`packs/FORMAT.md`](packs/FORMAT.md). בדיקת חבילה: `node .claude/commands/check-pack.js packs/<file>.json`.

החומר שלך (`materials/`) והחבילות שלך (`packs/`) מוחרגים מ־git ולא עולים לאינטרנט — רק חבילת הדמו.
