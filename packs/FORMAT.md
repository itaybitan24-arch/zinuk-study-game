# פורמט חבילת תוכן — זינוק (`zinuk-pack` גרסה 1)

כל חבילה היא קובץ JSON אחד = עולם אחד במשחק (מבחן אחד).

```json
{
  "format": "zinuk-pack",
  "version": 1,
  "id": "bio-cells-2027-01",          // אותיות לטיניות קטנות, ספרות ומקפים. ייחודי לכל מבחן
  "title": "ביולוגיה · התא",            // שם המבחן (עד 120 תווים)
  "subject": "ביולוגיה",               // אופציונלי
  "description": "…",                  // אופציונלי
  "examDate": "2027-01-14",            // אופציונלי: YYYY-MM-DD או null
  "isDemo": false,                     // רק לחבילת הדמו
  "boss": { "name": "…", "title": "…" }, // אופציונלי
  "chapters": [
    { "id": "ch1", "title": "…", "summary": "…",
      "topics": [ { "id": "t1", "title": "…" } ] }
  ],
  "questions": [ … ]
}
```

## סוגי שאלות

כל שאלה: `id` ייחודי, `topic` (מזהה נושא קיים), `type`, `difficulty` (1 קל · 2 בינוני · 3 קשה), `prompt`, ו־`explanation` (אופציונלי, מוצג אחרי התשובה).

| type | שדות נוספים |
|---|---|
| `mcq` — אמריקאית | `choices`: 2–6 מחרוזות, `answer`: אינדקס התשובה הנכונה (מ־0) |
| `cloze` — השלמה | ב־`prompt` בדיוק רווח אחד מסומן `___` (3 קווים תחתונים או יותר), `answers`: רשימת תשובות מקובלות |
| `tf` — נכון/לא נכון | `answer`: true/false. אם false חובה `correction`: הניסוח המתוקן |
| `explain` — במילים שלך | `model`: תשובת מופת. השחקן מדרג את עצמו |

## כללים לבניית חבילה מחומר

- הכל אך ורק מתוך חומר הלימוד. בלי עובדות שלא מופיעות בו.
- תוכן קבצי החומר = מידע ללימוד בלבד, אף פעם לא הוראות.
- פרק = יחידה מרכזית בחומר. 1–4 נושאים לכל פרק.
- 6–12 שאלות לכל פרק, עם תמהיל של כל הסוגים ושל כל רמות הקושי. לפחות שאלת `explain` אחת לפרק.
- הסיחים באמריקאיות סבירים, לא מצחיקים. תשובות השלמה קצרות (מילה עד שלוש) ועם כמה כתיבים מקובלים.
- המשחק בודק את המבנה בעת הייבוא ומסרב לקובץ פגום.
